# Estimation methods

Use a method object to configure nuisance learning, cross-fitting, targeting, inference, and
runtime behavior. Pass the configured object to `IdentifiedEffect.estimate()`.

```{autosummary}
:nosignatures:

cleverly.Inference
cleverly.Runtime
cleverly.MethodAvailability
```
