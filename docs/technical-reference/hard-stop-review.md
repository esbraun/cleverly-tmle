# Hard-stop review

This page records the review of the inherited hard stops in the future investigations grid of the
roadmap. The review applies the [Eligibility](../roadmap.md#eligibility) rule to each grid row. It
splits each row into sub-claims and gives each sub-claim one verdict. A sub-claim moves to a
main-roadmap row when an established method or a natural extension carries it. A sub-claim stays in
the [research queue](../roadmap.md#future-investigations) when it needs an argument of a new kind.

A verdict is not a capability. "Moves" means that the owning row may implement the part. The part
ships only when that row delivers its contract, its nonzero witnesses, and its registered study.
Until then the refusal stays, and it cites the owning row. The review read the code at `main`
commit `bb7a0ce`.

[X82](../roadmap.md#x82-refutation-and-sensitivity-checks-for-every-estimator) now owns the parts
that the review moved to X9, X11 (o), X47, X48, X49, X50 (e), X51 (f), X65 (a) to (i), X66 and
X67. The tables name each such part by its X82 part and table.

## The terms

| term | meaning |
| --- | --- |
| sub-claim | one request that a grid row refused, stated as one target, one estimator and one inference claim |
| refusal today | what the package does for the sub-claim. A quoted message gives its source location in `src/cleverly` |
| sources read | the sources the review read first-hand, with the version and the exact locator. [References](../references.md) records each first-hand read with its locators. An abstract-only read carries no verdict weight, and References can omit it |
| base result and steps | the published result that the extension starts from, and each step that carries it. Each step names its row in the standard-step table of [Eligibility](../roadmap.md#eligibility) |
| objection | a source that records a step as open or as a defect, or a step that needs an argument of a new kind |
| verdict | "moves" with its acceptance route, "keeps" with the kind of missing argument, "shipped" for a moved part that its owning row has delivered, "no action", "not adopted", or "not a claim of this row" |
| owning row | the main-roadmap row that implements a moved part, or the research-queue row that keeps the claim |

The research queue uses six kinds of missing argument.

| kind | the argument that is missing |
| --- | --- |
| identification | a law or an assumption that identifies the target from the observed data |
| regularity | a pathwise derivative of the target, or a model in which the estimator is regular |
| asymptotic | a limit theorem for the estimator as the package builds it, such as a remainder bound or a bootstrap consistency result |
| adaptive-optimum inference | a limit law after a data-adaptive selection, or for a target with no fixed limit |
| arbitrary dependence | an argument for a fixed number of dependent units |
| serial dependence | a limit theorem for split-based TMLE under mixing |
