# PR 264: clustered intervals at unequal sizes and few clusters

Reviewed merged commit `12fd6820d7745b59216f6add32feebb088e2c17e`, its PR description,
current implementation, unit instruments, study definitions, and committed verdict documents.
The implementation delivers X24's stated scope. It preserves explicit boundaries for few
clusters, simultaneous bands, longitudinal cross-fitting, and unsupported collaborative paths.

## Defects and repairs

1. **Weighted fold support (implementation defect).**
   `TMLE._preflight_cluster_validation_folds` counted every cluster label. Inference status and
   reference degrees of freedom count only clusters with positive weight mass. A fold with
   one positive-mass cluster and one zero-mass cluster therefore passed before learning, even
   though its fold variance had only one contributing total. F28 explicitly documented this
   defect as an open boundary. The preflight now reuses `fewest_clusters`, counts positive
   mass on each fold, and raises `CapabilityError` before any learner for zero or one
   contributing cluster. It retains the existing unweighted refusal text.
   `tests/unit/test_weighted_cluster_preflight.py` covers generated and supplied plans, both
   fold evaluation and fold targeting, zero and one positive-mass cluster, and an accepted
   two-contributing-cluster case. The refusal witnesses use learners that fail if called.

2. **Overstated reference derivation (scientific documentation defect).**
   Centering V fold means gives a pooled count J−V. It does not establish an exact t law for
   a sum of differently scaled, heterogeneous fold variances. For independent normal fold
   variance estimators with variance contributions c_v, Satterthwaite's effective count is
   `(sum(c_v))² / sum(c_v² / (J_v−1))`; a dominating fold approaches J_v−1, below J−V.
   The package's reference is a declared approximation measured by the registered study.
   `docs/technical-reference/inference.md` now makes that distinction and limits the
   classical J−1 comparison to independent normal totals with common variance. Related
   wording in `ClusterReference`, `minimum_reference_df`, and F28 was sent to the root
   agent for coordinated editing.

3. **Incorrect impossibility claim (roadmap documentation defect).**
   F28 claimed t_1 having no finite mean rules out any interval below four clusters.
   The distribution has finite confidence quantiles; a reference statistic does not need
   a mean to define such an interval. The supported package floor can remain, but it is
   an unvalidated boundary, not that mathematical impossibility. Root owns its correction.

## Practical and DRY review

The row-weighted ratio variance is correctly based on cluster totals `A_j − N_j psi`.
`test_cluster_ratio_variance.py` discriminates cluster sums from cluster means at unequal
sizes and independently rebuilds the total term from targeted predictions. The centered
fold-cluster correction has nonzero witnesses; the row branch preserves its existing
second-moment contract.

`ParameterEstimate.reference_df`, `stamp_inference`, and the common Wald helpers propagate
the reference through fitted and derived reports, tests, missingness tilts, omitted-variable
limits, bootstrap presentation, and band refusals. The central stamp and shared quantile
implementation avoid duplicated reference decisions. Reusing the positive-mass count in
the preflight closes a remaining duplicated decision that had drifted.

Including zero-total clusters in the existing weighted variance is not, by itself, evidence
of dilution: `check_weights` declares the iid-weights model and retains zero-weight rows in n.
At an exactly centered score, zeros alter the finite J/(J−1) correction, while weight
normalization and n cancel. Changing this variance model would need a separate declared
sampling contract; the support refusal repair does not make that change.

Fold-evaluated covariance deliberately differs from the stored fold variance and declares
the centered curve rule. This limitation is explicitly documented and tested in
`TestTheFoldEvaluatedCovarianceRule`; PR 264 did not silently introduce a new covariance
claim. Derived operations must retain that stated scope.

## Validation and study impact

No registered study has a zero-mass-cluster fold: the unequal weighting law uses positive
`1/N_j` weights, and the few-cluster study is unweighted. The support check therefore does
not change a registered fitted array, curve, variance, or verdict. No study regeneration
is required for this repair. Published red artifacts remain unchanged.
